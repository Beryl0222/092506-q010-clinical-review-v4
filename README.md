# 智能问答人工复核

面向医疗问答审核团队的复核服务。保存脱敏后的提问、回答版本、引用依据和风险标签，由规则决定哪些结果必须由医生确认或直接转人工；审核者可提出修改、退回和发布；已发布内容被新证据否定时撤回相关版本并通知仍在处理的会话。

## 核心规则

- **风险路由**：`emergency` 标签的会话在提交回答时直接转人工，禁止自动发布；`high` 标签的回答发布前必须由医生确认；`normal` 由审核员发布。
- **引用门槛**：引用依据（证据）带有效期；过期、被否定或不存在的证据不能作为发布依据。
- **版本回滚**：医生否定证据后，引用它的已发布版本被撤回，会话回到待处理并收到通知；在途待审核会话同样收到提醒。
- **确认门槛不可绕过**：提交与回调支持幂等键，重复提交返回首次结果；会话到终态后的延迟回调被忽略；发布按"待审核"状态条件更新，并发审核只有一人成功。
- **权限隔离**：角色仅 `reviewer` / `doctor`；高风险确认与证据否定仅限医生。
- **重启恢复**：状态保存在 SQLite 文件库，重启后 `list_unfinished` 恢复未完成会话继续处理。

## 目录

- `src/clinical_review/domain.py` 会话/版本/证据对象、状态机与发布门槛规则。
- `src/clinical_review/store.py` SQLite 表结构、幂等键与回调记录、状态条件更新。
- `src/clinical_review/service.py` 应用服务：提交、修改、退回、发布、升级、撤回、回调、恢复；时钟可注入。
- `src/clinical_review/api.py` JSON 请求适配层。
- `tests/` 验收测试：可控时钟与证据集覆盖高风险升级、引用过期、版本回滚、权限隔离、并发审核、重启恢复、幂等与延迟回调。

## 运行

运行测试：`PYTHONPATH=src python3 -m unittest discover -s tests`

检查源码：`python3 -m compileall src`

项目只使用 Python 标准库，测试和运行不需要启动其他服务。
